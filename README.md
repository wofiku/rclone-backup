# rclone-backup

Personal OAuth application page for **rclone** (Google Drive backend) used to keep
encrypted backups of the owner's own servers.

- Not a public product; single user (the repository owner).
- The app requests the `drive` scope only to read/write its own backups in the
owner's Google Drive.
- No data is collected, shared or transferred to third parties.
